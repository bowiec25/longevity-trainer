1. The big picture: from your primer to a quiz with receipts

All planned (dashed). The primer says what to learn; trusted sources say what's true. A card only exists if a script finds its quote in a pinned source.

Walk me through it
  • Your primer: the 92-page guide you wrote. It says what to learn, but it isn't proof.
  • Trusted sources: guidelines and reviews from named bodies (NIH, WHO, Cochrane…), saved with a fingerprint so we notice if they change.
  • card_writer: Claude writes a question, the answer, and the exact sentence from the source that backs it.
  • quote check: a script searches the saved source for that sentence. Not found → no card.
  • fact-auditor: a read-only Claude helper asks "does the answer really follow? Too strong? Missing a caveat?"
  • cards.jsonl: the checked cards. The quiz only reads this file.
